# Applied Machine Learning in Physics

Coursework, homework, reports, and supporting datasets for PHYS 2550.

## Contents

- `Homework 1/` — Linear regression from scratch on the UCI Real Estate Valuation dataset
  - Jupyter notebook with exploratory analysis, gradient descent, feature normalization, model comparison, and the closed-form bonus
  - Dataset files used by the notebook
  - LaTeX report source and figures in `report/`

Additional homework and project folders can be added at the repository root as the course continues.

## Running Homework 1

Open `Homework 1/PHYS_2550_Homework1.ipynb` in Jupyter and run all cells from top to bottom. The XLSX dataset must remain in the same folder as the notebook.
